## [2.0.0] - 2026-10-20

### Security

- Requires `google-adk >= 1.28.1, < 2.0.0` to address CVE-2026-4810.
- Raised minimum versions: `mcp >= 1.28.1`, `anyio >= 4.14.2`,
  `python-multipart >= 0.0.30`, and `pyasn1 >= 0.6.4`.
